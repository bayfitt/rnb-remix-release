# Public remix recipes

Every new music post includes the creative information needed for another person to remix it. Save a public recipe per song/version and link it from each platform post. Include the full exact music prompt and lyrics directly when the description limit permits; a short caption must still link the complete recipe. Read back the published description/caption to verify it.

A recipe contains:

- Reference title, artist, original public URL, uploaded excerpt start/end and optional SHA-256. Link to the source instead of redistributing the reference recording.
- Provider, endpoint, explicit model/version, actual request settings and candidate count. Replace private file/upload IDs with instructions to upload the reference. Describe unavailable seed/variance/duration controls honestly.
- Exact submitted style prompt and lyrics, including instrumental section labels, plus any later lyric edits.
- Every image/video generation prompt and character/reference instruction actually used, with the tool/model when known. For stock-only visuals, say no visual-generation prompt was used and include clip sources and licenses.
- Delivery edits that affect reconstruction: intro/outro trims, pitch/tempo changes, scene intervals, caption alignment method and export dimensions. Update these after rendering, rather than publishing planned edits as completed facts.

Publish the recipe in the authorized public workflow repository and use a commit-specific link for a completed release. Later amendments get a new link/version. Public lyrics and prompt records are authorized; account credentials, private task/upload IDs, signed download URLs, private recipient settings and raw third-party assets remain private. A recipe makes the method available; model variation means an identical output is not guaranteed.
