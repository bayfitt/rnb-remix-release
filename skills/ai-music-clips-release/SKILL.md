# AI music clips release

Create the requested song first, then the clip edit. Follow the user's creative choices, output count, release authorization, private channel settings, and standing sharing preferences. Do not repeat routine authorization questions already answered in the session.

1. Ask about the song settings before a new music API job and wait for answers: reference, lyrics/theme, what to preserve/change, vocal character/effects, tempo/key, delivery length, intro handling and candidate count. Explain the selected model/endpoint, supported controls and estimated cost. This is a creative-settings step, separate from previously settled rights/release authorization. Identify and save the reference's title, artists and URL, and read relevant previous-release comments. Write the requested replacement lyrics, with the main outcome/hook at the start. Use reference-based controls when available; preserve the requested melody, key, instruments and voice character as closely as the provider supports. Do not promise an exact reproduction or invent numeric variance controls. Follow the current quality/provider preference rather than an older cheap-model preference. For Mureka, see [current controls](references/mureka-controls.md). Submit once, save the task ID before polling, and reconcile an uncertain submission before spending again.
2. Save the finished audio, lyrics, prompt, provider timing data and costs. Remove an unwanted instrumental intro when a hook-first short is requested. Keep the generated master and the edited delivery audio. Preserve pitch and tempo unless the user asks for changes. Choose the short's duration from the actual sung content; do not cut required lyrics to force a duration the user did not specify.
3. Build a 9:16 motion-clip edit, with a new shot every three seconds unless overridden. Use new characters when requested. Pexels and Pixabay provide free video APIs that require API keys; their media use stock-content licenses, not open-source software licenses. Wikimedia Commons has freely licensed media with per-file conditions. Mixkit offers both commercial-use Free and personal-use-only Restricted video downloads: check the individual asset before using it. Respect access limits; do not bypass blocks. Save each selected clip's source URL, exact license, license-page evidence and checksum. Keep raw third-party clips out of the public workflow repository. Avoid implying a stock performer's endorsement or actual financial circumstances.
4. Create readable timed English lyrics from validated provider word/line timestamps. Shift every cue by any intro trim and check exact text, order, non-overlap and audio bounds. For shorts and vertical videos, burn very large, readable lyrics into the edit and retain editable SRT/VTT. Full horizontal videos use the selectable YouTube caption track without burned-in lyrics unless requested. Credit the reference song explicitly in the YouTube title and thumbnail. Put a legible remix/source label within the central image area as well, so an automatically cropped thumbnail retains it. Verify the audio/video decode, dimensions, duration, shot boundaries and representative captioned frames.
5. Prefer CLI operations for routine releases. Use Yutu for the canonical upload path, captions, thumbnail and comments; use `youtube-cli-app` for retention, watch-time/traffic analytics and channel profiles. Do not submit the same video through both tools. Both need a Google Desktop OAuth client and a one-time Google consent flow. Share one client/profile with `scripts/youtube_tools.py`, keep credentials and tokens outside the repository, and verify the returned channel ID against private settings before changing a channel. Enable YouTube Data API v3 and YouTube Analytics API v2 in the credential's Google Cloud project.
6. Publish the exact music prompt, lyrics, provider/model/endpoint, actual settings, reference excerpt and any visual prompts with each new post. Keep a public versioned recipe and verify its link in the published description; see [prompt sharing](references/prompt-sharing.md). Upload initially private, record the returned video ID immediately, and resume that ID after interruptions. Set Music, English, accurate made-for-kids and synthetic-media disclosures. Disable optional audio leveling/stabilization when preserving the rendered master. Upload the existing timed SRT as a standard English caption track with `--isDraft=false --isAutoSynced=false`; poll the saved caption ID until `status=serving` and `isDraft=false`. A newly inserted track can take time to appear in list responses; do not insert a duplicate. The helper clears Yutu v0.11.0's read-only caption defaults (`trackKind`, `audioTrackType`), which otherwise cause invalidMetadata errors. Set and verify the thumbnail; if custom thumbnails are unavailable, visually review and save evidence of the actual generated thumbnail retaining the reference label. Change visibility to public with the synthetic-media flag explicitly supplied again, then read back privacy, channel, metadata and caption state. YouTube can omit the synthetic-media flag in API reads even after accepting it; record an independent Studio check when needed. Report only checks actually performed; do not claim a Studio copyright check was performed through the API. Report any unresolved restriction.
7. Read available comments on the new release and record the check time and actionable feedback, or that none are available. Reading does not authorize replies or moderation. Pull requested analytics through `youtube-cli-app`; fresh videos can have no analytics data yet. Do not schedule ongoing monitoring unless asked.
8. Follow the user's explicitly authorized standing sharing preference for every platform or website used in the release. Include each new platform URL when cross-posting the same video, and share an existing private/test post's link when it becomes public. After the current batch and its required caption tracks are published, automatically send one consolidated message to the configured destination without routine reconfirmation, verify the recipient and outgoing message, and save a receipt to prevent duplicates. Retain pending links and report any failed send accurately. Include the workflow URL when requested. After successful workflow/tooling changes, validate and update the authorized GitHub workflow repository. Keep account identifiers, private messaging configuration, credentials and song assets out of that public update.

## CLI examples

The optional helper delegates to the upstream CLIs and converts the already-authorized profile token for Yutu; it does not request a second consent grant. `PROFILE` is a local channel profile.

```sh
youtube-tools --profile PROFILE status
youtube-tools --profile PROFILE connect --client /private/path/client_secret.json
youtube-tools --profile PROFILE yutu channel list --for mine --output json
youtube-tools --profile PROFILE yutu video insert --file video.mp4 --title 'Song | Reference Remix' --categoryId 10 --privacy private --language en --containsSyntheticMedia --forKids=false --autoLevels=false --stabilize=false --yes --output json
youtube-tools --profile PROFILE yutu caption insert --videoId VIDEO_ID --file captions.en.srt --language en --name 'English lyrics' --isDraft=false --isAutoSynced=false --yes --output json
youtube-tools --profile PROFILE yutu caption list --videoId VIDEO_ID --output json
youtube-tools --profile PROFILE yutu video update --id VIDEO_ID --privacy public --containsSyntheticMedia --yes --output json
youtube-tools --profile PROFILE yutu commentThread list --videoId VIDEO_ID --maxResults 100 --output json
youtube-tools --profile PROFILE cli analytics --days 28 --json
youtube-tools --profile PROFILE cli analytics --days 28 --dimensions insightTrafficSourceType --sort=-views --json
```

Use the installed versions' help before adapting these commands. Read-only checks and retries of queries are safe; uploads and message sends need stored duplicate guards. For caption verification, download the published track with `yutu caption download --id CAPTION_ID --file downloaded.srt --tfmt srt` and compare cue text and timestamps to the editable original. An anonymous `yt-dlp` check must request subtitle metadata (for example, `--list-subs`); a named English manual track may have an `en-ID` key rather than exactly `en`. Fresh thumbnail URLs can briefly return 404: refresh video metadata and check available sizes without repeating the upload.
